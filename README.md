# PZ3: Style Guide & Code Review Practice

Учебный проект по дисциплине «Технологии коллективной разработки информационных систем» (Практическая работа № 3, Вариант 4).

## Состав репозитория
- `STYLE_GUIDE.md` — командное руководство по стилю кодирования (комментарии, проверка типов и ввода, многопоточность, рефакторинг).
- `src/metrics_worker/` — модуль многопоточной обработки и агрегации метрик телеметрии.
- `tests/` — модульные тесты (`unittest`).
